## 1. Purpose and scope

This fictional evidence record describes a tabletop and sandbox test for a proposed cross-border payments feature for small-business customers. The proposed launch scope in the associated intake is Great Britain (GB) and the United States (US), using both the customer web portal and a business-to-business application programming interface (API). A fictional payment processor is identified in the intake as a third party.

The scenario document contains synthetic observations for GB web-channel screening only. It does not contain test results for the US, the API channel, the payment processor's environment, or production. It is intentionally incomplete so a reviewer can see how the workbench presents evidence context and how an AI-assisted draft may identify follow-up areas. No statement in this file establishes that a real control exists, operated, or was effective.

## 2. Fictional test setup

The scenario assumes a sandbox payment flow with a synthetic sender, synthetic beneficiary, and a simulated cross-border transfer. Names, payment references, amounts, timestamps, and outcomes are omitted; this demonstration must not be populated with real personal, account, or transaction data.

The fictional test scope includes:

- One GB web-channel payment journey from draft payment entry to simulated submission.
- A sanctions-screening test configuration using non-real test values.

- A high-level review of the proposed customer due diligence (CDD) step in the journey.

The scenario does not include independent validation, production logs, a control-owner sign-off, sample sizes, a complete test script, or an operating-effectiveness conclusion.
